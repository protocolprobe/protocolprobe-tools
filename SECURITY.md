# Security

Report a vulnerability in `protocolprobe-selftest` or `protocolprobe-discover` **privately**, not in a public issue:

- use GitHub's "Report a vulnerability" button on this repository's Security tab, or
- email hello@protocolprobe.com with the tool, its version and how to reproduce it.

Please do not include real tokens or keys. We answer reports about these tools; we do not give advice on testing servers
you do not own, and `selftest` must only be pointed at a server you run.
