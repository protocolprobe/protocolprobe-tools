# Contributing

Thank you for looking. Questions and ideas go in [Discussions](https://github.com/protocolprobe/protocolprobe-tools/discussions); a bug or a result you think is wrong goes in an [issue](https://github.com/protocolprobe/protocolprobe-tools/issues/new/choose).

## Pull requests

This repository is a public copy of two tools whose development happens in a private repository, and the copy is updated automatically. So we do not merge pull requests here. We read each one, apply an accepted change in the private repository, and the public copy then updates by itself. If you want to be named, say so in the pull request and we will name you in the release notes.

Please keep a pull request small, say which tool and version it is against, and never include a token, a key or the one-time proof value.

By sending a pull request you agree that it may be published under the ISC licence of this repository.

## What is not changed here

The facts on protocolprobe.com come from public records, not from this repository. A wrong fact is reported by email (see the contact page), so it can be checked and logged.
